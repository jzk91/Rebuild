# Rebuild

A personal workspace for practicing dynamic process simulation.

I am working through William L. Luyben's books on process modeling, simulation,
and control, and rewriting the numerical methods and process models from scratch:
root finding, ODE integration, and dynamic models of reactors and distillation
columns. The goal is to understand each piece well enough to build new models
on my own.

## Requirements

Python 3.10, NumPy, SciPy, Matplotlib, pytest

## Running the tests

    python -m pytest tests -q
